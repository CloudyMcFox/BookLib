BookLib for iOS requires access to a compatible
[self-hosted BookLib server](https://github.com/CloudyMcFox/BookLib).

## Before requesting help

1. Confirm that the server's web interface works in a browser.
2. Confirm that the server address in the app uses HTTPS and does not contain
   the web page's path.
3. Confirm that the same username and password work in the server's web
   interface.
4. Ask the server administrator whether the server is running the latest
   BookLib release.

## Documentation

Server installation, configuration, backup, and update instructions are in the
[BookLib README](https://github.com/CloudyMcFox/BookLib#readme).

## Report a problem

Search the [existing issues](https://github.com/CloudyMcFox/BookLib/issues)
before opening a new report. If the problem has not been reported, use the
[bug report form](https://github.com/CloudyMcFox/BookLib/issues/new/choose).

Include the app version, iOS version, server version, and steps to reproduce the
problem. Do not post passwords, access tokens, private server addresses,
database files, borrower information, or other personal library data.

Security vulnerabilities must be reported privately through
[GitHub's vulnerability reporting form](https://github.com/CloudyMcFox/BookLib/security/advisories/new),
not through a public issue.
